# Découpages scène par scène

Chaque fiche décrit un épisode scène par scène : lieu, personnages, qui parle à qui, action, gags, décor, costumes. Elle repose sur un visionnage par échantillonnage (une image toutes les 3 à 10 s selon l'épisode, plus serré sur les détails) et sur les sous-titres automatiques de YouTube. Le son n'a pas été écouté. Méthode : `../_methode/visionnage.md`.

Les dialogues ne sont pas retranscrits : l'action est racontée, avec au plus une dizaine de répliques courtes par épisode, issues des sous-titres automatiques donc non contrôlées à l'oreille.
