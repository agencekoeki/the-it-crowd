Onze cassettes, à charger dans l'ordre que vous voulez. La barre de couleur de chaque cassette donne la répartition de ses étiquettes de preuve, comptées dans le texte.

    
    
      
  • [VÉRIFIÉ] lu dans la source citée
    • 
      
  • [PROBABLE] déduit, pas lu tel quel
    • 
      
  • [À VÉRIFIER] fragile ou contradictoire
    • 
      
  • [ANALYSE] avis du rédacteur
    • 
      
  • [VU À L'IMAGE] constaté au visionnage

    Derrière la porte rouge : installer et contribuer
    
    
    Vous avez ouvert. Tant pis. Voici comment emporter l'encyclopédie chez vous, et comment la corriger sans vous fâcher avec la preuve.
    
    
    
      
    
        
    Installer chez soi
    
        
      
          
    1. Clonez le dépôt.
      git clone https://github.com/agencekoeki/the-it-crowd.git
      2. 
          
    2. Servez le dossier, puis ouvrez la page. Un serveur local permet à la page de charger les fiches.
      cd it-crowd && python3 -m http.server 8118
# puis http://localhost:8118/docs/
      3. 
          
    3. Pour votre propre vitrine : fourchez le dépôt, puis activez GitHub Pages sur le dossier /docs de la branche principale.
      4. 
          
    4. Si rien ne marche : éteignez, rallumez.
      5. 
        
    
      
    
      
    
        
    Contribuer
    
        
    Une correction vaut par sa source. Chaque fait ajouté porte une étiquette et la clé de la source lue.
    
        
    
          
    [VÉRIFIÉ]Lu dans la source citée. Pas « vu à l'écran ».
    
          
    [PROBABLE]Déduit de faits vérifiés. À ne pas citer comme établi.
    
          
    [À VÉRIFIER]Sources en désaccord, source unique fragile, ou souvenir.
    
          
    [ANALYSE]Interprétation du rédacteur. Pas une information.
    
          
    [VU À L'IMAGE]Constaté au visionnage, avec épisode et minutage.
    
        
    
        
    Les répliques se citent en VO, une ligne au plus. Aucune capture, aucun extrait : voir LICENSE-NOTES.md.
